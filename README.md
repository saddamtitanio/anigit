# AniGit

Version control for Krita animations: a visual timeline of commits, comparison, branching, merging,
search, and sharing with a team, like Git for animators.

```
gui/       the desktop app animators use                (in progress: structure only)
backend/   local backend: .kra files, history, merge    (not started)
server/    shared remote: accounts, files, branches     (built and tested)
docs/      feature lists for frontend, backend, AI search, and server
```
